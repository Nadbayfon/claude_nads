Privacy & Data

No data ever leaves this browser. Guest names, dietary info and seating exist only on this device — nothing is sent to any server.

Share with a couple: Use Save to download a .json file, email it. They open it with Load on their own device. Wedding-specific and completely private.

CSV import format:
Order, First name, Last name, Dietary
e.g. 1, Sarah, Johnson, Halal — header row is skipped automatically.

Archive: Save as 01-couples/[name]/seating-plan.json

Print / PDF: Sidebar hides on print. Only the floor plan exports.

Import from CSV

In Excel: File → Save As → CSV. Columns must be in this order:

Order, First name, Last name, Dietary

Example row: 1, Sarah, Johnson, Halal
Header row is skipped automatically.
Dietary is optional — leave blank if not needed.
Multiple dietary tags: use GF/Vegan

Existing guests (same name) will not be duplicated.
