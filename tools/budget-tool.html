Privacy & Data

No data leaves this browser. All budget data is stored locally on this device only.

Per-couple files: Use Save to download [couple-name].json. One file per couple. Load it whenever you have new information. Archive in 01-couples/[name]/budget.json.

Share with couple: Email the .json file. They open it in the same tool. In sandbox mode they can explore without changing the real numbers.

Sandbox mode: A copy of the real budget the couple (or you) can edit freely — changes are flagged and don't affect the confirmed budget unless you explicitly apply them.

Print / PDF: Clean printable view — controls and buttons are hidden.
